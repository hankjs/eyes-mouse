# IngridMeow

IngridMeow 是一款面向 Apple Silicon Mac 的指针工具，可以在选定的显示器上用眼动或头动控制指针。OpenCV 和 MediaPipe 在本机处理摄像头画面，进程之间只传输追踪特征、状态和坐标。用实体鼠标或触控板点击。

## 使用

1. 在「控制屏幕」选择一块已连接的显示器，默认选择系统主显示器。在「控制动作」选择「眼动（注视）」或「头动（转头与点头）」。应用会记住控制动作。
2. 如果「辅助功能权限」尚未授权，点击「授权辅助功能」，通过弹窗打开系统设置。在「隐私与安全性 → 辅助功能」开启 IngridMeow 后，应用会自动重新启动。
3. 开启相机并授予 macOS 相机权限。让相机清楚拍到两眼和脸部。校准时望向选定的屏幕，设置窗口可以放在另一块屏幕上。
4. 按所选动作完成设置，然后查看预览。
   - 眼动：选择「开始九点校准」。看准每个亮点后按空格，保持视线和头部稳定约一秒半。采样失败时可以在同一个亮点重试。按 Esc 可退出。五点精度验证以 macOS 逻辑点为单位。
   - 头动：面向屏幕，选择「设定正面位置」，保持稳定直到采样完成。左右转头可水平移动指针，抬头、低头可垂直移动。头回到正面时，指针停在当前位置。闭眼时仍可用头动。
5. 选择「启用指针」。如果指针在其他屏幕，启用时会将它移到所选屏幕中央。指针控制只在所选屏幕生效。按 Control + Option + P 可随时暂停。用鼠标或触控板把指针移出所选屏幕时，眼动和头动控制会暂停。

### 眼动阻尼

眼动模式下可随时拖动「眼动阻尼」滑杆。数值越低，指针和注视点预览跟随越快；数值越高，移动越稳。范围为 0–100，默认值为 50。调整即时生效，应用会记住设置。

### 校准头动补偿

使用 Mac 内建屏幕和内建相机时，九点校准会尝试拟合视线方向，并结合头部位置与朝向计算视线和屏幕的交点。启用这个模型时，界面会显示「内建屏幕几何」。屏幕尺寸来自 macOS，相机位置近似为屏幕上缘中央，头部深度来自 MediaPipe 的虚拟相机估计。轻微转头、点头或挪动头部时可用注视点预览检查效果。

外接屏幕、相机来源无法确认、几何拟合偏差过大或个别帧超出可用范围时，应用会沿用原九点映射。

完成九点校准后，如果轻微转头、点头或挪动头部会让眼动指针偏移，可以选择「校准头动补偿」。坐稳，注视中央亮点并按空格，接着一直看着亮点，按画面提示慢慢转头、抬头低头、左右和上下平移，再稍微前后移动。练习约 17 秒。采样失败或按 Esc 退出会保留原校准。完成后，可以在注视点预览中固定看着同一个位置，轻轻移动头部查看效果。

补偿使用练习中取得的头部活动范围。启用内建屏幕几何时，练习会学习几何预测剩余的偏差。快速甩头或转到相机看不清双眼时，追踪仍可能变差。成功校准头动补偿后，先前用鼠标保存的局部校正需要重新学习。重新做九点校准、切换控制屏幕或重启应用后，可重新练习。

### 用鼠标局部校正

完成九点校准后，如果眼动指针经常落在某个目标旁边，在控制屏幕上看准该目标约一秒，按 Control + Shift + M 暂停眼动指针。用鼠标或触控板把指针移到目标，再按一次 Control + Shift + M 保存。如果先前启用了眼动，且追踪仍可用，保存后会恢复眼动指针。

按 Control + Option + P 可取消，12 秒未确认也会取消。每次保存只改善目标附近的定位，五点精度验证会计入这些校正。校正保存在本次运行的校准中，切换控制屏幕、完成新的九点校准或重启应用后需要重新学习。

### 眼动手势

- 校准后保持头部稳定，沿屏幕中间一带依次看「左 → 右 → 左 → 右」，每边稍停，约一到两秒做完，即可启用或暂停指针。看向左右约三分之一处即可。切换后稍等一秒多便可重复。
- 在屏幕中央周围用视线逆时针画一整圈（右 → 上 → 左 → 下 → 右），约一到三秒，可退出应用。
- 完成当前显示器的九点校准后，快速闭合、睁开双眼三次会暂停指针并打开全屏快速回正。依次注视中央、左上和右下的亮点，保持头部稳定，等亮点自动切换。中央用于修正视线偏移，两个角落用于确认原校准仍然适用。失败或按 Esc 退出时会保留上次校准。回正结束后，指针处于暂停状态。

切换控制屏幕、移动摄像头或改变坐姿后，重新校准眼动或设定正面位置。所选显示器断开时会暂停控制，可以改选其他显示器。重新启动应用后，控制屏幕默认使用系统主显示器，需要重新校准。头动模式在相机重开或重新选用时需重新设定正面位置。

### 贪吃喵

打开 IngridMeow 时会自动启动「贪吃喵」。游戏浮在主显示器的工作区，点击、滚动和键盘输入照常传给正在使用的窗口。英格丽德喵从左侧或右侧追着系统指针，给指针留出空隙。每次追赶会随机跑步、爬行或飞翔，追赶速度随距离变化。停下来时会冒出爱心、嚼点心或低头张望，指针一移动就会继续追赶。指针离开工作区时会停在原地。

英格丽德喵身边起初有两颗金色小光点。吃下工作区里的光点后，它们会绕着身体转。大的光点追得慢，移动时拖出更长的光尾。角色停稳后，所有光点在两秒内归位并收起光尾。三个小光点会聚成一个中光点，三个中光点会聚成一个大光点，三个大光点会展开一道金色法阵，随后消散。待拾取的光点出现 15 秒后会消失。每个光点被拾取或消失时，独立随机补出 0–3 个，工作区最多同时有 9 个待拾取光点。场上清空时，随机生成 1–9 个。开启 macOS 的「减少动态效果」后，光点会停在角色身旁，法阵原地淡出。

在主窗口点击「重新开始」或「关闭游戏」即可控制游戏。关闭后，可在主窗口右上角点击「贪吃喵」重新打开。屏幕校准、头动补偿校准、验证和快速回正期间，已开启的游戏会暂时隐藏，退出后接着玩。

切换主显示器上的 macOS 桌面时，游戏浮层会随当前桌面显示，并保留角色位置、随行光点和待拾取的光点。设置窗口也会随普通桌面切换。

关闭相机时可用鼠标或触控板玩，也可以先启用眼动或头动指针再进入游戏。

## 本地开发和打包

在 Apple Silicon macOS 15 或更新版本上准备 Node.js 22.12+、Rust 1.93+、Xcode 命令行工具、arm64 Python 3.14 和 uv。

```sh
npm ci
sh tracker/setup.sh
npm run tauri -- dev
```

开发模式下，系统可能将相机授权归到启动应用的终端。测试实际权限时可使用打包后的应用。

首次打包时，请在 macOS 钥匙串准备有效的代码签名证书及其私钥。使用 Developer ID Application 证书，或使用此 Mac 已信任的本地代码签名证书。运行以下命令，找到要使用的证书名称及其前面的 40 位十六进制指纹。

```sh
security find-identity -v -p codesigning
```

将指纹保存为 `~/Library/Application Support/IngridMeow/signing-identity` 的唯一一行，也可在尚未保存指纹时用 `APPLE_SIGNING_IDENTITY` 指定。两处皆已设定时，指纹必须一致。后续构建请保留并继续使用同一签名证书及其私钥。打包命令会在构建前检查签名身份，并验证产物与追踪组件的签名。

```sh
npm run bundle:mac
```

`npm run bundle:mac` 和 `make bundle-mac` 都会生成已验证签名的安装包。直接运行 `tauri build` 会跳过上述签名检查。默认产物为 `src-tauri/target/aarch64-apple-darwin/release/bundle/macos/IngridMeow.app`，其中包含追踪组件及模型。构建需要下载依赖和模型，应用运行时的跟踪在本机完成。

从 Eyes Mouse 升级后，请在「系统设置 → 隐私与安全性 → 辅助功能」为 IngridMeow 新授予权限。IngridMeow 的应用标识为 `com.hankjs.gazemouse`，系统会将它与 Eyes Mouse 的旧条目分开识别。如果 IngridMeow 尚未保存控制动作或眼动阻尼，会分别读取旧应用保存的有效设置。

从旧的临时签名构建升级时，请退出应用并替换原位置的 `IngridMeow.app`。在「辅助功能」用「−」移除旧的 IngridMeow 条目，再用「+」添加并启用已安装的新版本。之后使用同一签名身份更新同一位置的应用，可沿用这次授权。

## 资源参考

在 Apple M2、macOS 15.6.1 上，用同一张测试人像模拟 640×480、24 FPS 的单脸追踪。20 秒内识别了 480 帧，Python 追踪进程平均占用 0.21 个 CPU 核，RSS 中位数 138 MiB、采样峰值 170 MiB。BGR 转 RGB 和模型推理的 P95 耗时为 10.84 ms。

整应用的前期预算是 0.25–0.45 个 CPU 核和 250–450 MiB 合计 RSS。这个范围是预算。实机摄像头采集、Tauri WebKit 开销、功耗及端到端指针延迟仍需测量。

当前应用包大小约 108 MiB。跟踪进程启动后会临时解包约 246 MiB 文件，进程退出时会清理。
