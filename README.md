# Eyes Mouse

Eyes Mouse 是一款面向 Apple Silicon Mac 的单屏指针工具，可以用眼动或头动控制指针。OpenCV 和 MediaPipe 在本机处理摄像头画面，进程之间只传输追踪特征、状态和坐标。用实体鼠标或触控板点击。

## 使用

1. 将应用窗口放在主显示器，在「控制动作」选择「眼动（注视）」或「头动（转头与点头）」。应用会记住选择。
2. 开启相机并授予 macOS 相机权限。
3. 按所选动作完成设置，然后查看预览。
   - 眼动：选择「开始九点校准」。看准每个亮点后按空格，保持注视约一秒。按 Esc 可退出。五点精度验证以 macOS 逻辑点为单位。
   - 头动：面向屏幕，选择「设定正面位置」，保持稳定直到采样完成。左右转头可水平移动指针，抬头、低头可垂直移动。头回到正面时，指针停在当前位置。闭眼时仍可用头动。
4. 选择「启用指针」，在「系统设置 → 隐私与安全性 → 辅助功能」授予权限后再次启用。按 Control + Option + P 可随时暂停。切换控制动作、关闭相机或因跟踪丢失而暂停后，需再次启用指针。

### 眼动阻尼

眼动模式下可随时拖动「眼动阻尼」滑杆。数值越低，指针和注视点预览跟随越快；数值越高，移动越稳。范围为 0–100，默认值为 50。调整即时生效，应用会记住设置。

### 眼动手势

- 校准后保持头部稳定，在屏幕中央周围用视线画一整圈，约一到三秒。以自己的屏幕为准，右 → 下 → 左 → 上 → 右是顺时针，可启用或暂停指针。反向画圈可退出应用。画完后把视线移回中央，再画下一圈。
- 快速闭合、睁开双眼三次会暂停指针并打开全屏快速校准。依次注视中央、左上和右下的亮点，保持头部稳定，等亮点自动跳到下一处。按 Esc 可取消并保留之前的校准。校准结束后，指针处于暂停状态。

移动摄像头、改变坐姿或切换主显示器后，重新校准眼动或设定正面位置。重新启动应用后需要重新设置。头动模式在相机重开或重新选用时需重新设定正面位置。

### 贪吃蛇

在主窗口右上角点击「贪吃蛇」，再点击「开始」。游戏浮在主显示器的桌面上，下面的窗口仍然可见。移动系统指针引导蛇头，吃下食物会变长，吃完一批后会出现 1–3 个新食物。碰到蛇身后可点击「再玩一次」，按 Esc 或点击「退出」可关闭游戏。

关闭相机时可用鼠标或触控板玩，也可以先启用眼动或头动指针再进入游戏。

## 本地开发和打包

在 Apple Silicon macOS 15 或更新版本上准备 Node.js 22.12+、Rust 1.93+、Xcode 命令行工具、arm64 Python 3.14 和 uv。

```sh
npm ci
sh tracker/setup.sh
npm run tauri -- dev
```

开发模式下，系统可能将相机授权归到启动应用的终端。测试实际权限时可使用打包后的应用。

```sh
npm run bundle:mac
```

产物为 `src-tauri/target/release/bundle/macos/Eyes Mouse.app`。跟踪组件及模型随应用打包，并使用本地 ad hoc 代码签名。构建需要下载依赖和模型，应用运行时的跟踪在本机完成。

## 资源参考

在 Apple M2、macOS 15.6.1 上，用同一张测试人像模拟 640×480、24 FPS 的单脸追踪。20 秒内识别了 480 帧，Python 追踪进程平均占用 0.21 个 CPU 核，RSS 中位数 138 MiB、采样峰值 170 MiB。BGR 转 RGB 和模型推理的 P95 耗时为 10.84 ms。

整应用的前期预算是 0.25–0.45 个 CPU 核和 250–450 MiB 合计 RSS。这个范围是预算。实机摄像头采集、Tauri WebKit 开销、功耗及端到端指针延迟仍需测量。

当前应用包大小约 108 MiB。跟踪进程启动后会临时解包约 246 MiB 文件，进程退出时会清理。
